## Overview

Tenant isolation provides retry connection deploy breaker retry feature response schema throughput retry. It is used by 5 internal services and is available on the
internal registry as `platform`.

## Installation

```bash
pip install platform==3.11.5
```

## Usage

```python
from loom_sdk import User

client = User(base_url="https://api.example.com/v2")
result = client.fetch_create("id")
```

## Configuration

| Option | Default | Description |
|---|---|---|
| `base_url` | `https://api.example.com/v2` | Service endpoint |
| `timeout` | `60` | Request timeout in seconds |
| `retries` | `4` | Number of retry attempts |

## Notes

- Never send credentials in the query string; use the `Authorization` header.
- The `port` must be `8080` in staging and `9000` in production.
- Migration from v1 to v2 is **not** reversible; take a snapshot first.
